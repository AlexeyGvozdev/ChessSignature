## 🔧 Технические детали

### Интеграция с ViewModel
- Использует `GameViewModel` для управления состоянием
- Собирает состояние через `collectAsState()`
- Обрабатывает все пользовательские взаимодействия

### Валидация ввода
- Отображает индикаторы валидации: ✅ (валидно), ⚠️ (неполный), ❌ (ошибка)
- Цвет фона меняется в зависимости от состояния валидации
- Показывает сообщения об ошибках при необходимости

### Копирование в буфер обмена
- Интеграция с `ClipboardManager` Android
- Snackbar уведомление об успешном копировании
- Использует emoji 📋 для кнопки копирования

### Управление состоянием
- Реактивное обновление через StateFlow
- Неизменяемое состояние с копированием при обновлениях
- Корректная обработка пользовательского ввода

## 📱 Компоненты

### ColorSelector
- FilterChip для выбора цвета первого хода
- Поддержка белых (⚪) и черных (⚫)
- Интеграция с `GameViewModel.setStartingColor()`

### PieceSelector
- Два ряда кнопок для выбора фигур
- Первый ряд: Пешка, Конь, Слон
- Второй ряд: Ладья, Ферзь, Король
- Использует `PieceType.toDisplayString()` для названий

### SquaresGrid
- Сетка 8x8 с правильными шахматными цветами
- Координаты от a8 до h1
- Обработка кликов через `ChessSquare.fromString()`

### ChessKeyboard
- Три ряда кнопок:
  - Специальные символы: x, +, #, =
  - Рокировки: O-O, O-O-O
  - Управление: ←, Очистить, ✓
- Заголовок "Клавиатура:" согласно документации

### CurrentMoveDisplay
- Отображение текущего ввода
- Индикатор валидации
- Цвет фона в зависимости от состояния
- Сообщения об ошибках

### MovesListWithCopy
- Список ходов с группировкой по парам
- Кнопка копирования с emoji 📋
- Пустое состояние при отсутствии ходов
- LazyColumn для эффективной прокрутки
